# Pieper Dach GmbH – Website

OnePager-Website für die Pieper Dach GmbH, Brandenburg. Dachdeckerei & Zimmerei seit 2001.

## Lokale Vorschau

`index.html` direkt im Browser öffnen – kein lokaler Server erforderlich.

## GitHub Pages aktivieren

Settings → Pages → Branch: `main` / Folder: `/ (root)` → Save

## Stack

- HTML5 / CSS3 / Vanilla JS
- Three.js (CDN) – 3D Hero-Animation
- GSAP ScrollTrigger (CDN) – Scroll-Animationen
- Google Fonts: Oswald + Source Sans 3
