# Handwerk Muster-Website Quality Rubric

Use this rubric when auditing or planning sample websites for local German trades and home-service businesses.

## Scorecard

| Area | Strong | Weak |
|---|---|---|
| Positioning | Trade, region, customer problem, and outcome are obvious immediately. | Generic "Ihr Partner für Qualität" language. |
| Local fit | Service area, local proof, and regional search language are natural. | City names sprinkled into otherwise generic copy. |
| Trust | Concrete proof: team, Meisterbetrieb, projects, reviews, warranty, materials, response process. | Abstract trust claims without evidence. |
| Conversion | CTA matches intent and urgency; mobile contact is effortless. | Only a generic contact button or buried form. |
| Service clarity | Each service explains scope, signs/problems, process, and next step. | List of services without useful decision context. |
| Visuals | Images show real craft, materials, properties, people, or completed work. | Abstract backgrounds or unrelated stock imagery. |
| SEO foundation | Title/meta, H1, internal links, schema, alt text, sitemap, robots present. | Missing basics or over-optimized keyword stuffing. |
| Mobile UX | Readable, tappable, no overlap, contact path visible. | Desktop layout squeezed onto phone. |

## Recommended Structures

### Dachdecker / Roofing

Home, Leistungen, Dachsanierung, Dachreparatur, Flachdach, Dachfenster, Fassaden/Klempnerarbeiten when relevant, Projekte, Einzugsgebiet, Kontakt.

Key proof: weather protection, warranty, materials, before/after, emergency repair, scaffolding/process clarity.

### Sanitär / Heizung / Bad

Home, Badmodernisierung, Sanitärinstallation, Heizung, Wartung, Notdienst if offered, Projekte, Förder-/Effizienzhinweise if true, Kontakt.

Key proof: clean site work, planning process, brands, energy competence, response reliability.

### Elektriker

Home, Elektroinstallation, Sanierung/Altbau, Smart Home, Photovoltaik/Wallbox if offered, E-Check, Notdienst if offered, Kontakt.

Key proof: safety, certification, standards, documentation, quick diagnostics.

### Maler / Fassade

Home, Innenanstrich, Fassadengestaltung, Tapezieren/Spachteln, Bodenbeläge if offered, Projekte, Farbberatung, Kontakt.

Key proof: surface preparation, color guidance, clean execution, before/after.

### Gartenbau / Landschaftsbau

Home, Gartengestaltung, Pflaster/Terrassen, Pflege, Zaun/Sichtschutz, Projekte, Saisonleistungen, Kontakt.

Key proof: material feel, project galleries, seasonal timing, maintenance plans.

### Tischler / Schreiner

Home, Möbel nach Maß, Innenausbau, Türen/Treppen, Reparaturen, Materialien, Projekte, Kontakt.

Key proof: precision, materials, workshop, drawings/process, durability.

## Copy Patterns

Use specific German CTAs:

- "Kostenlose Ersteinschätzung anfragen"
- "Rückruf für Ihr Projekt vereinbaren"
- "Vor-Ort-Termin im Raum [Stadt] buchen"
- "Notdienst anrufen"
- "Dachcheck anfragen"
- "Badmodernisierung besprechen"

Avoid empty claims unless backed by proof:

- "Qualität aus Leidenschaft"
- "Ihr kompetenter Partner"
- "Alles aus einer Hand"
- "Individuelle Lösungen"

These can appear only when followed by concrete evidence.

## Local SEO Checklist

- Unique title with trade, service, and primary city/region.
- Meta description with service area and CTA.
- One descriptive H1.
- Service sections/pages with natural location language.
- NAP placeholders: name, address/service area, phone, email.
- `LocalBusiness` or relevant subtype JSON-LD.
- Opening hours or response-time language when relevant.
- Project/review content with local context.
- `robots.txt` and `sitemap.xml` for standalone demos.
- Image alt text that names service and visible subject.

## Visual Direction Prompts

Good visual premises:

- Precise workshop craft with warm daylight and material texture.
- Clean modern renovation site with visible completed detail.
- Owner-operated local team in front of vehicle/workshop.
- Before/after project story with restrained UI.
- Emergency service interface with clear phone-first layout.

Avoid:

- Abstract gradient heroes.
- Generic city skylines without craft relevance.
- Over-polished corporate SaaS layouts.
- Dark blurred stock photos where the craft cannot be inspected.
- Random icon grids as the main proof.
